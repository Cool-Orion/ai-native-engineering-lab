# AI-Native Engineering Lab｜人工智能原生工程学习系统

这个仓库不只是练习代码，而是一个持续迭代的 Learning Operating System（学习操作系统）。

核心循环：

**Goal（目标） → Issue（任务议题） → Learn / Build（学习 / 构建） → Pull Request / PR（拉取请求） → Review（审查） → Evidence（证据） → Skill Map（能力地图）更新 → Curriculum（课程路线）更新**

## Current Learning Goals｜当前学习目标

- Learn the fundamentals of Git（学习 Git 基础）
- Understand the GitHub workflow（理解 GitHub 工作流）
- Practice AI-native engineering（实践人工智能原生工程）

## System Files｜系统文件

- [`CURRICULUM.md`](./CURRICULUM.md)：当前版本的学习路线，以及路线更新规则
- [`SKILL-MAP.md`](./SKILL-MAP.md)：基于证据的当前能力地图
- [`labs/`](./labs/)：短周期实验，用来理解概念和验证假设
- [`projects/`](./projects/)：用于证明能力的真实项目

## Operating Rules｜运行规则

1. 学习任务尽量用 Issue（任务议题）定义。
2. 可交付成果尽量通过 Pull Request / PR（拉取请求）进入主分支。
3. Agent（智能体）可以负责大量实现，但人类必须理解目标、关键逻辑和验收证据。
4. “课程学完”不等于能力获得；Skill Map（能力地图）只有在出现实践证据后才更新。
5. 当人工智能能力、官方工作流或真实项目反馈发生变化时，允许修改 Curriculum（课程路线）。
6. 系统保持简洁：不为了管理而管理，不把仓库变成笔记堆积区。

## Current Focus｜当前重点

当前阶段：**Phase 1 — Coding Agent 与结果验证**

当前实验：让 Coding Agent（代码智能体）根据结构化 Issue（任务议题）实现 Learning Goals CLI（学习目标命令行程序），然后由人类审查代码、测试和 Acceptance Criteria（验收标准）。
